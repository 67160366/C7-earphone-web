    ข้อความจากบอร์ด

      อ่านค่าในหน้านี้

      ค่ามาจากไหน

      • ชิปวัดเอง: accel (m/s²) และ gyro (°/s) ของทั้ง 3 ตัว
      • ชิปคำนวณมาให้: quaternion ของหูทั้งสองข้าง BNO085 รวม accel + gyro + เข็มทิศให้ในตัวชิป พร้อมความแม่นยำ 0–3
      • บอร์ดจดเพิ่ม: อายุค่าของแต่ละเซ็นเซอร์ (ms) ใช้ดูว่าสองหูในบรรทัดเดียวกันอ่านห่างกันเท่าไร บอร์ดอ่านสลับซ้าย-ขวาทีละแพ็กเก็ตให้ห่างกันน้อยที่สุด
      • หน้าเว็บคำนวณเพิ่ม:
        • มุม x/y/z ของหู แปลงจาก quaternion เป็นมุมรอบแกนของชิป
        • มุมต้นคอ x/y จาก accel และ z จากการรวม gyro ซึ่งค่าจะค่อย ๆ เพี้ยน
        • แกน 3 มิติ ทิศที่แต่ละแกนชี้ ความเร่งเมื่อตัดแรงโน้มถ่วง และมุมระหว่างสองหู
      • MPU6050 ที่ต้นคอไม่มี quaternion และแรงโน้มถ่วงบอกได้แค่ว่าเอียง แต่บอกไม่ได้ว่าหันไปทางไหน

      อ่านแกน 3 มิติ

      • ลูกศรส้ม = แกน x, เขียว = y, ม่วง = z ของชิปแต่ละตัว แผ่นสี่เหลี่ยมคือตัวชิป ลูกศรสีเข้ม a คือ accel ในทิศโลก ตอนนิ่งต้องชี้ขึ้น
      • ตามที่ติดจริง: แสดงทิศของชิปตามที่ติดบนหูฟัง สองหูติดกลับด้านกันจึงชี้คนละทาง
      • จัดแนวให้ตรงกัน: ใช้ท่าตอนกด "ตั้งท่าเริ่มต้น" ทำให้หูขวาเหมือนติดแนวเดียวกับหูซ้าย ถ้าศีรษะหมุนทั้งชิ้น แกนสองหูจะซ้อนกันสนิทตลอด ส่วนที่ต่างคือ δ
      • ซ้อนกัน: วางแกนทั้งหมดไว้ที่จุดเดียว หูขวาเป็นเส้นจาง ใช้ดูคู่กับ "จัดแนวให้ตรงกัน"
      • ลากในภาพเพื่อหมุนมุมกล้อง เลื่อนล้อเพื่อซูม

      อ่านกราฟ

      • เส้นส้ม = x, เขียว = y, ม่วง = z ย้อนหลัง 10 วินาที เลขมุมซ้ายบน/ล่างคือค่าสูงสุด/ต่ำสุดที่เห็น
      • มุม: นิ่ง = เส้นแบน ขยับแล้วเลื่อนตามท่า มุมกระโดดจาก +180 ไป −180 เป็นเรื่องปกติของการวัดมุม
      • accel: นิ่งแล้วมีแกนหนึ่งใกล้ ±9.8 ที่เหลือใกล้ 0
      • gyro: นิ่งแล้วใกล้ 0 มีหนามตอนหมุน ถ้ามีหนามสูงทั้งที่วางนิ่ง แปลว่าผิดปกติ
      • δ ซ้าย-ขวา: ควรใกล้ 0 ถ้าเกิน 10° หูฟังข้างหนึ่งหลวม
