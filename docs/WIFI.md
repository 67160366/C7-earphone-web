# ส่งข้อมูลผ่าน Wi-Fi เข้าเซิร์ฟเวอร์

เพิ่มเมื่อ 2026-11-16 **ยังไม่ได้ flash ลงบอร์ด ยังไม่เคยมีบอร์ดจริงส่งข้อมูลเข้ามา** เซิร์ฟเวอร์ตอนนี้คือคอมพิวเตอร์เครื่องนี้ ส่วนที่ตรวจแล้วและยังไม่ได้ตรวจอยู่ใน [../HANDOFF.md](../HANDOFF.md)

USB ยังใช้ได้เหมือนเดิม (JSON v2 ที่ 460800 baud) Wi-Fi เป็นทางส่งเพิ่มอีกทางหนึ่ง

## ภาพรวม

```
หูฟัง (ESP32) ──Wi-Fi──> https://<เซิร์ฟเวอร์>/api/ingest.php ──> MySQL (c7_devices 1 ─< c7_readings)
                                                                      │
เบราว์เซอร์ ── devices.html ──> api/devices.php <──────────────────────┘
```

- บอร์ดไม่ต่อ MySQL ตรง ๆ ชื่อผู้ใช้และรหัสฐานข้อมูลอยู่บนเซิร์ฟเวอร์ที่เดียว (`api/config.local.php`) ไม่อยู่ในเฟิร์มแวร์
- บอร์ดยืนยันตัวด้วย "รหัสส่งข้อมูล" (`ingest_key`) ใน header `X-C7-Key`
- แต่ละบอร์ดมี `device_uid` ของตัวเอง (`c7-` ตามด้วย MAC) เซิร์ฟเวอร์เพิ่มบอร์ดใหม่ใน `c7_devices` เองเมื่อเห็นครั้งแรก จึงรับหลายบอร์ดพร้อมกันได้โดยไม่ต้องลงทะเบียนก่อน

## ฐานข้อมูล (1 device → หลาย readings)

ไฟล์: [../api/db_schema.sql](../api/db_schema.sql) `ingest.php` สร้างตารางเองตอนรับข้อมูลครั้งแรก

| ตาราง | 1 แถวคือ | คอลัมน์หลัก |
| --- | --- | --- |
| `c7_devices` | หูฟัง 1 เครื่อง | `id` (PK), `device_uid` (UNIQUE), `name`, `firmware`, `last_seen_at`, `last_valid`, `last_sensors`, `last_boot_id`, `last_ip`, `created_at` |
| `c7_readings` | ค่าที่วัด 1 ครั้ง | `id` (PK), `device_id` (FK → `c7_devices.id`, ลบบอร์ดแล้วค่าหายตาม), `boot_id`, `seq`, `recorded_at` (มิลลิวินาที), `calibration_id`, `head_pitch`, `head_roll`, `head_yaw`, `mpu_tilt` (NULL = ไม่มี MPU), `cva_angle`, `sensors` |

- `UNIQUE (device_id, boot_id, seq)` ทำให้ส่งซ้ำแล้วไม่เกิดแถวซ้ำ
- `INDEX (device_id, recorded_at)` สำหรับดึงค่าย้อนหลังของบอร์ดเดียว
- `cva_angle` เซิร์ฟเวอร์คิดซ้ำด้วยสูตร geometry 1 (`api/cva.php`) ทุกแถว ค่าที่บอร์ดส่งมาไม่ตรงสูตรถูกปฏิเสธ
- ตัวอย่างที่ยังไม่มีค่ามุม (`valid=false`) ไม่ถูกเก็บ แต่ยังอัปเดต `last_seen_at`
- ค่าเริ่มต้นส่ง 5 ค่าต่อวินาที = ราว 432,000 แถวต่อเครื่องต่อวันถ้าเปิดทั้งวัน ปรับ "ส่งค่าทุกกี่มิลลิวินาที" ในหน้าตั้งค่าของบอร์ดได้ (100–60000)
- ตารางเดิม `posture_logs` (หน้า dev, `save_angle.php`) ไม่เกี่ยวกับชุดนี้และไม่ถูกแตะ

## ใช้เครื่องนี้เป็นเซิร์ฟเวอร์ (วิธีที่ใช้อยู่ตั้งแต่ 2026-11-16)

เซิร์ฟเวอร์ angsila ใช้ไม่ได้ จึงให้คอมพิวเตอร์เครื่องนี้รับข้อมูลแทน ฐานข้อมูลเป็น SQLite ที่ `data/c7.sqlite` (ตารางเดียวกัน สร้างเอง ไม่ต้องติดตั้ง MySQL)

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/serve.ps1 -Lan
```

- `-Lan` ให้ server รับจากอุปกรณ์อื่นในเครือข่าย (ไม่ใส่ = รับเฉพาะเครื่องนี้) และพิมพ์ที่อยู่ที่ต้องกรอกในบอร์ด
- `scripts/router.php` ปฏิเสธ `.git`, `.local`, `data/`, `scripts/` และไฟล์ฐานข้อมูล ไม่ให้เครื่องอื่นในเครือข่ายดาวน์โหลด
- `api/config.local.php` ชี้ไป SQLite แล้ว และมี `ingest_key` สั้น 10 ตัวไว้กรอกในบอร์ด
- เปิดดูที่ `http://127.0.0.1:8090/devices.html`

บอร์ดกับคอมพิวเตอร์ต้องอยู่เครือข่ายเดียวกันและมองเห็นกัน มี 2 ทาง:

| ทาง | ที่อยู่เซิร์ฟเวอร์ที่กรอกในบอร์ด | หมายเหตุ |
| --- | --- | --- |
| **Mobile hotspot ของ Windows** (แนะนำ) เปิดที่ Settings → Network & internet → Mobile hotspot เลือกย่าน 2.4 GHz แล้วให้บอร์ดต่อ Wi-Fi ของ hotspot นั้น | `http://192.168.137.1:8090/api/ingest.php` (เป็นค่าเริ่มต้นในเฟิร์มแวร์แล้ว) | เลขนี้ของ Windows ไม่เปลี่ยน ไม่ต้องแก้อีก |
| Wi-Fi เดียวกับคอมพิวเตอร์ | `http://<IP ของเครื่อง>:8090/api/ingest.php` (ดูจากที่ `serve.ps1 -Lan` พิมพ์) | IP เปลี่ยนได้เมื่อต่อ Wi-Fi ใหม่ Wi-Fi ของมหาวิทยาลัยอาจกันไม่ให้อุปกรณ์คุยกันเอง หรือต้องล็อกอิน ซึ่งบอร์ดทำไม่ได้ |

Windows Firewall ต้องอนุญาต `php.exe` ถ้าบอร์ดขึ้น `http=-1` ให้ตรวจข้อนี้ก่อน

## ติดตั้งบนเซิร์ฟเวอร์อื่น (ยังไม่ได้ทำ)

1. คัดลอกทั้งโฟลเดอร์โปรเจกต์ไปไว้ใต้ `public_html` ของบัญชีบนเซิร์ฟเวอร์ (ค่าเริ่มต้นในเฟิร์มแวร์สมมติว่าเป็นโฟลเดอร์ `c7` คือ `https://angsila.informatics.buu.ac.th/~<ชื่อผู้ใช้>/c7/`) ไม่ต้องคัดลอก `.git`, `.local`, `data`
2. คัดลอก `api/config.local.php` จากเครื่องนี้ไปที่ `api/` บนเซิร์ฟเวอร์ด้วย (ไฟล์นี้ไม่อยู่ใน git มีชื่อผู้ใช้ รหัสฐานข้อมูล และ `ingest_key`) ถ้ายังไม่มีให้คัดลอกจาก `api/config.sample.php`
3. เปิด `https://<เซิร์ฟเวอร์>/.../devices.html` ถ้าขึ้น "ติดต่อเซิร์ฟเวอร์ได้" และ "ยังไม่มีเครื่องใดส่งข้อมูล" แปลว่าต่อฐานข้อมูลและสร้างตารางได้แล้ว

ต้องมี PHP 7.0 ขึ้นไปพร้อม `pdo_mysql` และ MySQL 5.6.4 / MariaDB 5.3 ขึ้นไป (`DATETIME(3)`) ไม่ต้องใช้ `mbstring`

ข้อควรรู้เรื่อง angsila (ตรวจ 2026-11-16 จากเครื่องนี้): ชื่อ `angsila.informatics.buu.ac.th` ชี้ไป `10.80.4.16` ซึ่งเป็นเลขภายใน และตอบ HTTPS ได้ ถ้าจากเครือข่ายนอกมหาวิทยาลัยชื่อนี้ยังชี้ไปเลขภายใน บอร์ดต้องต่อ Wi-Fi ที่อยู่ในเครือข่ายของมหาวิทยาลัยจึงจะส่งถึง (ยังไม่ได้ตรวจจากเครือข่ายนอก)

## ตั้งค่าบอร์ด (ไม่ต้องแก้เฟิร์มแวร์)

1. เปิดบอร์ด ถ้ายังไม่เคยตั้งค่า บอร์ดจะเปิด Wi-Fi ชื่อ **`C7-Setup-xxxx`** (รหัส `c7setup1`)
2. ต่อ Wi-Fi นั้นจากมือถือหรือคอมพิวเตอร์ แล้วเปิด `http://192.168.4.1/` (มือถือส่วนใหญ่จะเด้งหน้านี้เอง)
3. แตะชื่อ Wi-Fi จากรายการ "Wi-Fi ที่พบรอบตัว" (บอกความแรงสัญญาณและมีรหัสหรือไม่ กด "ค้นหาใหม่" เพื่อสแกนอีกรอบ หรือพิมพ์ชื่อเองถ้า Wi-Fi ซ่อนชื่อ) แล้วกรอก รหัส Wi-Fi, ที่อยู่เซิร์ฟเวอร์ (ที่อยู่ของ `api/ingest.php`), รหัสส่งข้อมูล (`ingest_key` ใน `api/config.local.php`), ชื่ออุปกรณ์, ช่วงเวลาส่งค่า แล้วกด "บันทึกและเริ่มใหม่"
4. บอร์ดเริ่มใหม่และต่อ Wi-Fi ที่ตั้งไว้ ค่าทั้งหมดเก็บในหน่วยความจำของบอร์ด (NVS) อยู่ข้ามการปิดเปิดและการ flash

บอร์ดจำ Wi-Fi ได้ 3 วง (เฟิร์มแวร์ `c7-wifi-2`): เข้าโหมดตั้งค่าแล้วเลือกวงใหม่เพื่อเพิ่ม เลือกชื่อเดิมเพื่อแก้รหัส หรือติ๊ก "ลบ" หน้าวงที่ไม่ใช้ ถ้าบันทึกไว้มากกว่า 1 วง บอร์ดจะสแกนแล้วต่อวงที่สัญญาณแรงที่สุดก่อน ต่อไม่ได้ใน 20 วินาทีจึงลองวงถัดไป

เปลี่ยนค่าภายหลัง: **กดปุ่ม BOOT ค้าง 3 วินาที** หรือส่งคำสั่ง **`w`** ทาง USB บอร์ดจะกลับเข้าโหมดตั้งค่า (กด BOOT สั้น ๆ ยังเป็นการตั้งท่าเริ่มต้นเหมือนเดิม)

บอร์ดเข้าโหมดตั้งค่าเองเมื่อ ต่อ Wi-Fi ที่บันทึกไว้ไม่ได้สักวง (วงละ 20 วินาที) หรือหลุดเกิน 60 วินาทีแล้วไม่มีวงอื่นให้ต่อ และถ้าไม่มีใครต่อเข้ามาตั้งค่าใน 3 นาที จะลองต่อ Wi-Fi ที่บันทึกไว้อีกครั้ง

ขณะต่อ Wi-Fi อยู่ เปิด `http://<IP ของบอร์ด>/` เพื่อดูสถานะได้ (อ่านอย่างเดียว) IP ดูได้จากบรรทัด `[ESP-LOG] NET ...` ทาง USB

ข้อจำกัด:
- ใช้ได้กับ Wi-Fi 2.4 GHz ที่ใส่รหัสผ่านอย่างเดียว หรือไม่มีรหัส **ไม่รองรับ** Wi-Fi ที่ต้องใส่ชื่อผู้ใช้ (WPA2-Enterprise ขึ้นในรายการแต่กดเลือกไม่ได้) หรือล็อกอินผ่านหน้าเว็บ Wi-Fi 5 GHz ไม่ขึ้นในรายการ
- Wi-Fi ที่กันอุปกรณ์ในวงไม่ให้เห็นกัน (พบบ่อยใน Wi-Fi สาธารณะ) บอร์ดต่อติดแต่ส่งถึงเซิร์ฟเวอร์ในวงเดียวกันไม่ได้
- ระหว่างสแกน (ราว 3 วินาที) มือถือที่ต่อ `C7-Setup-xxxx` อยู่อาจสะดุดชั่วครู่ เพราะบอร์ดมีวิทยุชุดเดียว
- HTTPS ไม่ตรวจใบรับรองของเซิร์ฟเวอร์ (`setInsecure()`) ข้อมูลเข้ารหัสระหว่างทางแต่ไม่กันการปลอมเป็นเซิร์ฟเวอร์
- ส่งไม่สำเร็จ = ทิ้งชุดนั้น ไม่เก็บไว้ส่งย้อนหลัง
- `api/devices.php` อ่านได้โดยไม่ต้องใช้รหัส ใครเปิดที่อยู่นี้ได้ก็เห็นค่ามุมและ `device_uid`

## บรรทัดสถานะทาง USB

```
[ESP-LOG] NET device_uid=c7-xxxxxxxxxxxx firmware=c7-wifi-2 url=... period=200ms key=set saved_wifi=1
[ESP-LOG] NET Wi-Fi connected ip=10.x.x.x rssi=-55dBm
[ESP-LOG] NET online ip=... rssi=... sent=120 fail=0 drop=0 http=200      (ทุก 10 วินาที)
```

`http=401` = รหัสส่งข้อมูลไม่ตรง, `http=404` = ที่อยู่เซิร์ฟเวอร์ผิด, `http=503` = เซิร์ฟเวอร์ต่อฐานข้อมูลไม่ได้, ค่าลบ = ต่อเซิร์ฟเวอร์ไม่ได้

## API

`POST api/ingest.php` header `X-C7-Key`, body:

```json
{"device_uid":"c7-a1b2c3d4e5f6","name":"หูฟังเครื่องที่ 1","firmware":"c7-wifi-2","boot_id":123456,
 "protocol_version":2,"geometry_id":1,
 "samples":[{"seq":0,"age_ms":815,"cal":1,"sensors":7,"valid":true,
             "head_pitch":3.2,"head_roll":0.5,"head_yaw":-1.0,"mpu_tilt":1.4,"cva_angle":50.61}]}
```

- `age_ms` = ตัวอย่างนี้วัดมาแล้วกี่มิลลิวินาทีตอนส่ง เซิร์ฟเวอร์ใช้คิด `recorded_at` (บอร์ดไม่มีนาฬิกา)
- `sensors`: bit0 หูซ้าย, bit1 หูขวา, bit2 MPU ที่ต้นคอ
- ไม่เกิน 100 ตัวอย่างต่อครั้ง ตอบ `{"status":"ok","device_id":1,"saved":5,"duplicates":0,"rejected":[]}`

`GET api/devices.php` ทุกบอร์ดพร้อมค่าล่าสุด และ `GET api/devices.php?device=<id>&limit=<1-600>` ค่าย้อนหลังของบอร์ดเดียว

## ทดสอบ

```powershell
node scripts/check-api.mjs
```

เปิด PHP server ของตัวเองที่พอร์ต 8091 กับฐานข้อมูล SQLite ชั่วคราว (24 ข้อ: รหัสผิด, ส่งซ้ำ, 6 บอร์ดส่งพร้อมกัน, ค่าไม่ตรงสูตร ฯลฯ) ไม่แตะ MySQL และไม่แตะไฟล์ตัวอย่างใน `api/` คำสั่ง MySQL ใน `db_schema.sql` ต้องตรวจบนเซิร์ฟเวอร์จริง

Compile เฟิร์มแวร์: เหมือนเดิม (ดู HANDOFF) ใช้ partition เริ่มต้นได้ (86%)
