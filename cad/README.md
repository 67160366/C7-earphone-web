# ไฟล์สำหรับพิมพ์ 3 มิติ (กล่อง C7 + ตลับข้างหู)

ชิ้นพิมพ์ทั้ง 10 ชิ้นสร้างจากขนาดใน [`assets/structure-layout.js`](../assets/structure-layout.js) ชุดเดียวกับหน้า `structure.html` ถ้าแก้ขนาดในหน้านั้น ให้สร้างไฟล์ใหม่ อย่าแก้ STL หรือ `params.scad` เอง

**สถานะ: ยังไม่ได้พิมพ์จริง ยังไม่ได้ประกอบ** ขนาดบางชิ้นยังเป็นค่าประมาณ (ดูหัวข้อ "ต้องวัดก่อนพิมพ์")

## สร้างไฟล์
ต้องมี Node 18 ขึ้นไป และ OpenSCAD 2021.01 ขึ้นไป (`winget install --id OpenSCAD.OpenSCAD -e`)

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-cad.ps1
```

ได้ไฟล์ใน `cad/out/` (**เข้า git แล้ว โหลดไปพิมพ์ได้เลย ไม่ต้องติดตั้งอะไร**): `<ชิ้น>.stl`, `<ชิ้น>.3mf` (วางในทิศพิมพ์แล้ว) และ `<ชิ้น>.png` ไว้ดูภาพ รวมทั้ง `assembly.png` (ภาพแยกชั้น)

| ตัวเลือก | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `-Fit` | 0.25 | ระยะเผื่อรอบบอร์ด ตะขอ และขอบฝา (มม.) |
| `-HoleAdd` | 0.15 | ขยายรูทุกรู เพราะรูพิมพ์ออกมาเล็กกว่าแบบ (มม.) |
| `-Screw` | `pilot` | `pilot` = รูนำสกรูเกลียวปล่อย, `insert` = รูน็อตทองเหลือง heat-set ที่เสาฝากล่อง (M2.5) และรางแผ่นหนีบ (M3) |
| `-PodCable` | 1.2 | ความสูงจากพื้นตลับถึงลิ้นของแคลมป์รัดสาย = ความหนาสาย Qwiic (มม.) |
| `-Only` | ทุกชิ้น | เช่น `-Only c7_lid,pod_lid_L` |
| `-NoPng`, `-No3mf` | | ข้ามภาพหรือ 3MF ให้เร็วขึ้น |

ไฟล์ใน git สร้างด้วยค่าเริ่มต้นเสมอ `cad/out/build.json` บอกค่าที่ใช้ และ `node scripts/check-web.mjs` จะล้มถ้า layout เปลี่ยนแล้วยังไม่ได้สร้างไฟล์ใหม่ ถ้าสร้างด้วยค่าอื่นเพื่อพิมพ์เอง (เช่น `-Fit 0.3`) ห้าม commit ให้รันสคริปต์ด้วยค่าเริ่มต้นอีกครั้งก่อน commit

เปิดแก้ใน OpenSCAD GUI: เปิด `cad/part.scad` แก้ `which = "..."` แล้วกด F6 ส่วน `cad/assembly.scad` แสดงทุกชิ้นตามตำแหน่งประกอบ (`explode = 0` คือปิดกล่อง)

## ชิ้นที่พิมพ์ (PETG)
| ไฟล์ | ชิ้น | ทิศพิมพ์ |
| --- | --- | --- |
| `c7_base` | ฐานกล่อง 96 × 60 × 33 มม. + ราง 2 เส้นหลังกล่อง | พื้นลงแท่น **เปิด support เฉพาะจากแท่น** ใต้พื้นกล่อง (รางยื่นจากพื้น 5 มม.) |
| `c7_tray` | ถาดบอร์ด 91 × 55 × 2 มม. | วางราบ |
| `c7_lid` | ฝากล่อง | คว่ำลงแท่น (ปลอก 2 ต้นและขอบชี้ขึ้น) |
| `c7_clamp` | แผ่นหนีบแถบ 64 × 40 × 2.5 มม. | วางราบ |
| `pod_base_L`, `pod_base_R` | ฐานตลับข้างหู 39 × 28.5 × 7.8 มม. | พื้นลงแท่น |
| `pod_lid_L`, `pod_lid_R` | ฝาตลับ มีตะขอ 4 ตัว และลูกศรชี้ด้านหน้าแบบร่องลึก 0.4 มม. | คว่ำลงแท่น |
| `pod_clamp_L`, `pod_clamp_R` | แคลมป์รัดสาย 8 × 3.6 มม. | คว่ำลงแท่น |
| `test_fit` | ชิ้นทดลอง (ไม่นับใน 10 ชิ้น) | วางราบ |

ตั้งค่าแนะนำ: ชั้น 0.2 มม., ผนัง 3 เส้น, infill 30–40 %, PETG 230–245 °C แท่น 70–80 °C (ปรับตามเส้นที่ใช้)

## ลำดับที่แนะนำ
1. พิมพ์ `test_fit` ก่อน (ราว 20 นาที)
   - แถวรู (ซ้ายไปขวา): M2 นำ, M2.5 นำ, M3 นำ, M2.5 insert, M3 insert, M2.5 ลอด, M3 ลอด
   - เสา 6 มม. มีรูนำ M2.5: ลองขันสกรู M2.5×6 เกลียวปล่อย
   - กรอบ GY-521 3 ขนาด (ร่องบอก 1/2/3 ขีด = fit − 0.1 / fit / fit + 0.1)
2. ปรับ `-Fit` และ `-HoleAdd` ตามผล แล้วสร้างไฟล์ใหม่
3. พิมพ์ตลับข้างหู 1 ข้าง ลองใส่ BNO085 กับสายจริง แล้วค่อยพิมพ์กล่อง C7

## ส่วนที่ต่างจากภาพในหน้า structure
แบบในหน้า structure ไม่ได้ตรวจการชนกันของครีบและตะขอ ตัวสร้างไฟล์ปรับให้ดังนี้ (ตอนสร้างไฟล์จะพิมพ์บรรทัด `adjusted:` ออกมา):
- **Qwiic Adapter 2:** ตะขอฝั่งผนังบนไม่มีที่ (บอร์ดห่างผนัง 1.15 มม.) จึงเปลี่ยนเป็นครีบใต้ฝากล่องกดขอบบอร์ดแทน
- **TP4056:** มุมกั้นมุมซ้ายบนชนตัวเก็บประจุ 470 µF จึงเอาออก ส่วนตะขอฝั่งซ้ายย้ายจากปลายบนไปปลายล่างของด้านเดียวกัน
- **สวิตช์:** ครีบกั้นด้านซ้ายเอาออก เพราะห่างจาก TP4056 แค่ 1 มม.
- **เสา 3 ต้นที่ชิดผนัง:** มีครีบเชื่อมเข้าผนัง (เดิมแตะผนังแค่เป็นเส้น จึงไม่เป็นชิ้นตันที่พิมพ์ได้)
- **แคลมป์สายในตลับ:** เพิ่มเสารับสกรู M2 (Ø3.2 มม. ห่างบอร์ด BNO085 0.1 มม.) และลิ้นกดสาย
- **ตะขอฝาตลับ:** เพิ่มปุ่ม 0.4 มม. ที่ปลายตะขอ และร่องรับในผนังฐาน

## ต้องวัดก่อนพิมพ์ (ยังเป็นค่าประมาณ)
- ขนาดแผ่น Qwiic Adapter (แบบใช้ 25.4 × 12.7 มม.) และระยะแถวขา ESP32 (แบบใช้ 25.4 มม.)
- ตำแหน่งรูยึดของ BNO085 และ GY-521
- ความหนาสาย Qwiic (`-PodCable`) และความหนาของที่ดามนิ้วกับฟองน้ำ (รางรับได้ 5 มม.)

## จุดที่บาง
- เสา 6 มม. กับ insert M2.5 (รู 3.75 มม.) เหลือผนัง 1.1 มม. และรางกว้าง 6 มม. กับ insert M3 (รู 4.15 มม.) เหลือผนัง 0.9 มม. ถ้าแตกให้ใช้ `-Screw pilot`
- เสารับสกรูของแคลมป์ในตลับมีผนังราว 0.7 มม. และผนังตลับหนา 1.5 มม. ร่องรับตะขอทำให้เหลือ 0.9 มม.
- สกรู M2.5×4 ของ BNO085: รูลึก 2.4 มม. ปลายสกรูห่างผิวนอกพื้นตลับ 0.3 มม.

## ไฟล์
| ไฟล์ | หน้าที่ |
| --- | --- |
| `scripts/cad-model.mjs` | คำนวณรูปทรงทุกชิ้นจาก layout (กล่อง ทรงกระบอก ลำดับบวกลบ) ไม่มี dependency |
| `scripts/export-cad.mjs` | เขียน `cad/params.scad` (ไฟล์ที่สร้างอัตโนมัติ เข้า git เพื่อให้เปิดใน OpenSCAD ได้ทันที) |
| `scripts/build-cad.ps1` | รัน export แล้วเรียก OpenSCAD ส่งออก STL / 3MF / PNG ตรวจว่าเป็นชิ้นตันที่พิมพ์ได้ (ไม่มี `Simple: no`) และเขียน `cad/out/build.json` |
| `cad/out/` | ไฟล์พิมพ์ที่สร้างแล้ว (ค่าเริ่มต้น) เข้า git ยกเว้น `_src/` |
| `cad/lib.scad` | แปลงข้อมูลใน `params.scad` เป็นชิ้นงาน |
| `cad/part.scad`, `cad/assembly.scad`, `cad/test_fit.scad` | ชิ้นเดียวในทิศพิมพ์ / ภาพประกอบ / ชิ้นทดลอง |
