# C7-BioSync web design system

แหล่งอ้างอิงที่ใช้: ui-ux-pro-max (ข้อมูล Healthcare App, typography "Thai Modern", pre-delivery checklist), taste-skill (copy tells, motion tokens) และหลักออกแบบของ frontend-design/artifact-design
ทั้งสอง skill ถูก clone มาเก็บไว้ที่ `D:\work\_design-skills` เพื่ออ่านเป็นข้อมูลอ้างอิงเท่านั้น ไม่ได้รันสคริปต์ในนั้น

## โจทย์
- **ผู้ใช้**: คนทำงานหน้าจอที่สวมหูฟัง C7 ระหว่างนั่งทำงาน เปิดหน้าเว็บค้างไว้ข้างจอ แล้วเหลือบมองเป็นครั้งคราว
- **งานเดียวของหน้าผู้ใช้**: บอกให้รู้ทันทีว่าตอนนี้คอตั้งตรงหรือเริ่มยื่น และเตือนเมื่อยื่นนานเกินไป
- **หน้า dev**: ตรวจบอร์ด เซ็นเซอร์ และ protocol ได้โดยไม่ต้องเปิด Serial Monitor

## สิ่งที่หยิบมาจากโลกของงานนี้
นักกายภาพวัด CVA จากภาพด้านข้าง โดยลากเส้นจากกระดูก C7 ไปที่ติ่งหู (tragus) แล้ววัดมุมกับเส้นแนวนอนด้วยไม้โปรแทรกเตอร์
หน้าผู้ใช้จึงใช้ **โปรแทรกเตอร์ด้านข้าง** เป็นองค์ประกอบหลักแทนเกจทั่วไป:
- ภาพเงาศีรษะและคอด้านข้าง จุด C7 อยู่ที่จุดหมุน
- เส้น C7→หู คือเข็ม
- ส่วนโค้งมีขีดบอกทุก 5° และแบ่งสีเป็น 3 โซน: ท่าดี / เริ่มก้มคอ / คอยื่น
- ความกล้าในดีไซน์ใช้ไว้ที่จุดนี้จุดเดียว ส่วนอื่นเรียบ

## สี (token; ธีมมืดเปลี่ยนเฉพาะค่า)
| token | สว่าง | มืด | ใช้กับ |
| --- | --- | --- | --- |
| `--ground` | `#EDF1EF` (เทาอมเขียวแร่) | `#0F1614` | พื้นหลังหน้า |
| `--surface` | `#FFFFFF` | `#17201D` | พื้นที่หลักที่ยกขึ้นมา |
| `--ink` | `#13221E` | `#E3ECE8` | ข้อความหลัก |
| `--ink-2` | `#4A5B56` | `#9DB0AA` | ข้อความรอง (ทั้งสองธีม ≥ 4.5:1) |
| `--line` | `#CBD5D1` | `#2C3935` | เส้นแบ่ง ขีดโปรแทรกเตอร์ |
| `--accent` | `#0F6E66` (เขียวหัวเป็ดเข้ม) | `#3CC9B8` | ปุ่มหลัก โฟกัส ลิงก์ |
| `--good` | `#167A45` | `#4ADE80` | สถานะท่าดี |
| `--warn` | `#A15C07` | `#F5B83D` | เริ่มก้มคอ |
| `--bad` | `#B42318` | `#F87171` | คอยื่น |
- สีสถานะแยกจาก accent และทุกสถานะมีคำกับรูปทรงกำกับเสมอ: ท่าดี = วงกลม, เริ่มก้มคอ = สามเหลี่ยม, คอยื่น = สี่เหลี่ยม
- ไม่ใช้ gradient, เงานุ่ม ๆ ทุกการ์ด หรือ glassmorphism

## ตัวอักษร
- เสนอ **IBM Plex Sans Thai** (OFL) สำหรับข้อความ และ **IBM Plex Mono** สำหรับตัวเลขในหน้า dev
- เก็บไฟล์ฟอนต์ไว้ในเครื่องที่ `assets/fonts/` เพื่อให้ใช้แบบออฟไลน์ได้ ต้องดาวน์โหลดก่อน และยังรอผู้ใช้อนุญาต
- ถ้าไม่ใช้ฟอนต์นี้ จะใช้ฟอนต์ของระบบแทน: `"Leelawadee UI","Noto Sans Thai","Sarabun",system-ui,sans-serif`
- Type scale (1.25): 13 / 16 / 20 / 25 / 31 / 39 / 61 px โดยข้อความทั่วไปใช้ 16 px และ line-height 1.6 (ภาษาไทยมีวรรณยุกต์ซ้อน)
  - คำสถานะใช้ 39 px
  - ตัวเลขมุมใหญ่ใช้ 61 px
- ตัวเลขทุกตัวใช้ `tabular-nums`
- ไม่มี label ตัวพิมพ์ใหญ่ทั้งหมด ไม่มี eyebrow เหนือหัวข้อ ไม่มีลูกศร → ต่อท้ายปุ่ม

## ระยะและรูปทรง
- ระยะห่างยึดจังหวะ 4/8: 4, 8, 12, 16, 24, 32, 48
- มุมโค้ง: ปุ่ม 10 px, พื้นที่หลัก 16 px, ชิป 999 px ตัวโปรแทรกเตอร์ไม่มีกรอบ
- เป้ากดต้องมีขนาด 44 px ขึ้นไป และโฟกัสใช้วงแหวน 3 px สี `--accent`

## การเคลื่อนไหว (ตาม taste motion tokens)
| สิ่งที่ขยับ | ระยะเวลา |
| --- | --- |
| hover เข้า | 150 ms |
| hover ออก | 120 ms |
| กดปุ่ม | 90 ms |
| เปิด panel | 200 ms |
| เข็มโปรแทรกเตอร์ลื่นตามค่า | 240 ms |

- ease: `cubic-bezier(.2,.8,.2,1)`
- ช่วงเดียวที่ตั้งใจให้เด่นคือตอนตั้งท่าเริ่มต้น: นับถอยหลัง 3-2-1 แล้วเส้นอ้างอิงค่อย ๆ วาดขึ้น
- เมื่อเปิด `prefers-reduced-motion` ทุกอย่างกระโดดไปที่ค่าปลายทางทันที

## หน้าผู้ใช้ `index.html`
เดสก์ท็อป (≥ 900 px) ทุกอย่างอยู่ในหน้าจอเดียว:
```
┌──────────────────────────────────────────────────────────────┐
│ C7-BioSync              (●) พร้อมใช้งาน              [ตั้งค่า] │
├──────────────────────────────────────┬───────────────────────┤
│                                      │ ● ท่าดี                │
│      โปรแทรกเตอร์ + เงาศีรษะด้านข้าง      │ คอตั้งตรงดี ทำต่อไปได้เลย  │
│      เส้น C7→หู ขยับตามจริง              │                       │
│                                      │ 51°                   │
│                                      │ เทียบกับท่าเริ่มต้น 52°     │
│                                      │                       │
│                                      │ [ตั้งท่าเริ่มต้นใหม่]      │
├──────────────────────────────────────┴───────────────────────┤
│ วันนี้   ท่าดี 82%   ใช้งาน 1 ชม. 20 นาที   เตือน 3 ครั้ง          │
│ ▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇  30 นาทีล่าสุด                  │
└──────────────────────────────────────────────────────────────┘
```
มือถือ (≤ 600 px) เรียงเป็นคอลัมน์เดียว: สถานะ → โปรแทรกเตอร์ → ปุ่ม → สรุปวันนี้

ก่อนเชื่อมต่อ ฝั่งขวาแสดงขั้นตอนเริ่มใช้ 3 ขั้น ส่วนโปรแทรกเตอร์แสดงท่าอ้างอิงจาง ๆ โดยไม่มีเข็ม:
```
1  เสียบสาย USB ของหูฟังเข้ากับคอมพิวเตอร์
2  [เชื่อมต่อหูฟัง]   เลือกพอร์ต CP210x / USB Serial
3  นั่งหลังตรง มองตรง แล้วกด [ตั้งท่าเริ่มต้น]
   ยังไม่มีหูฟัง? ดูตัวอย่างการทำงาน
```

เมื่ออยู่ในท่า "คอยื่น" ต่อเนื่องนานเกินเวลาที่ตั้งไว้ (ค่าเริ่มต้น 10 วินาที) จะมีแถบเต็มความกว้างขึ้นด้านบน:
`■ คอยื่นมา 12 วินาทีแล้ว  ยืดคอขึ้น ดึงคางเข้าเล็กน้อย` แถบหายเองเมื่อกลับมาท่าดี

## หลักการเขียนข้อความ
- เขียนจากมุมผู้ใช้ ใช้คำกริยาตรง ๆ: "เชื่อมต่อหูฟัง", "ตั้งท่าเริ่มต้น", "ตัดการเชื่อมต่อ"
- ข้อความผิดพลาดต้องบอกว่าเกิดอะไรและต้องทำอะไรต่อ เช่น "ไม่พบเซ็นเซอร์หูซ้าย เสียบสายหูฟังให้แน่นแล้วรอ 3 วินาที"
- ไม่ใช้คำโฆษณาหรือคำเชิงคุณธรรมพร่ำเพรื่อ ไม่ใช้อีโมจิแทนไอคอน
- ไม่อ้างว่าเป็นการวินิจฉัยทางการแพทย์ CVA ที่แสดงเทียบกับท่าเริ่มต้นที่ผู้ใช้ตั้งเอง

## Checklist ก่อนส่งงาน (จาก pro-rules)
- contrast ≥ 4.5:1 ทั้งสองธีม, ปุ่มกดได้ขนาด ≥ 44 px, โฟกัสมองเห็นได้, ไอคอนชุดเดียว (inline SVG เส้น 1.75 px)
- ไม่สื่อสถานะด้วยสีอย่างเดียว, `aria-live` บอกการเปลี่ยนสถานะ, เปิด reduced motion แล้วยังใช้งานได้
- ทดสอบที่ 375 px / 768 px / 1440 px ทั้งธีมสว่างและธีมมืด และต้องไม่มีสกรอลแนวนอน
