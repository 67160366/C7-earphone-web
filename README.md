# C7-BioSync Earphone Posture Monitoring System (Protocol v2)

ระบบตรวจจับและวิเคราะห์มุมกระดูกคอ (Craniovertebral Angle: CVA) แบบ 3 มิติแบบเรียลไทม์ โดยใช้เซนเซอร์ BNO085 คู่ (ซ้าย-ขวา) ร่วมกับ MPU6050 ที่ต้นคอ (C7) และแสดงผลผ่านหน้าเว็บที่เชื่อมหูฟังทาง USB โดยตรง (Web Serial API)

---

### เปิดใช้งาน

ต้องมี PHP 8+ (หรือ XAMPP) และเปิดด้วย Chrome หรือ Edge บนคอมพิวเตอร์ (Web Serial):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/serve.ps1        # เปิด server
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/serve.ps1 -Stop  # ปิด server
node scripts/check-web.mjs                                                     # เทสต์
```

แล้วเปิด http://127.0.0.1:8090/ (ข้อมูลจำลอง: `/?demo`, หน้า dev: `/dev.html`, เก็บข้อมูล: `/collect.html`, แบบอุปกรณ์เสริม: `/wiring.html`) เฟิร์มแวร์กับหน้าเว็บต้องเป็นรุ่นเดียวกัน (460800 baud) ถ้าบอร์ดยังเป็นรุ่น 115200 ต้อง flash ใหม่ ปิดโปรแกรมอื่นที่ใช้พอร์ต USB เดียวกัน (เช่น Serial Monitor ของ Arduino IDE) ก่อนกดเชื่อมต่อ

## 🔍 สาเหตุของปัญหาที่พบ และการแก้ไขเรื่อง I2C Address ชนกัน

### 1. ปัญหาที่พบ (Root Cause: On-Board Pull-Up & Address Collision)
- โมดูลเซนเซอร์ **BNO085 (GY-BNO08X)** มีตัวต้านทาน **Pull-up (หรือการกำหนดค่าเริ่มต้นบนแผ่นบอร์ด)** ต่ออยู่ที่ขาเลือก Address (`DI` / `SA0` / `ADR`) อยู่แล้ว ทำให้ตัวบอร์ดมี I2C Address ตั้งต้นของตัวเองอยู่แล้วตั้งแต่จ่ายไฟ
- ก่อนหน้านี้เราไม่ทราบว่าบอร์ดมี Pull-up และมี Address กำหนดไว้แล้ว จึงทำการต่อสายกำหนด Address ซ้ำเหมือนกันทั้ง 2 ตัว (หรือเข้าใจสลับกันว่าปล่อยว่างคืออีกค่าหนึ่ง) ส่งผลให้เซนเซอร์ทั้ง 2 ตัวกลายเป็น **Address เดียวกัน** บนบัส I2C เดียวกัน (`Wire` ขา `SDA=21, SCL=22`)
- เมื่อเซนเซอร์ 2 ตัวมี Address ชนกันบนบัสเดียวกัน จึงเกิดอาการแย่งกันตอบ ACK / ข้อมูล SHTP ตีกัน ทำให้ทำงานพร้อมกันสองตัวไม่ได้ หรือเห็นเซนเซอร์ขึ้นแค่ตัวเดียว

### 2. การแก้ไขให้เซนเซอร์ทำงานพร้อมกันได้ทั้ง 2 ตัว (Dual BNO085 Solution)
- **แยก I2C Address ของเซนเซอร์ทั้ง 2 ตัวให้ต่างกันอย่างชัดเจน:**
  - **หูซ้าย (`LeftEar_A`)** กำหนดเป็น Address **`0x4A`**
  - **หูขวา (`RightEar_B`)** กำหนดเป็น Address **`0x4B`**
  - **ต้นคอ (`C7` - MPU6050)** ใช้ Address **`0x68`**
- **ตรวจสอบด้วย I2C Scanner (`s`) และล็อกตำแหน่งในโค้ด:**
  - ปรับโค้ดใน `detectAndInitDualBno()` ให้สแกนหาและจับคู่ `0x4A` เป็นเซนเซอร์ฝั่งซ้าย (เริ่มทำงานตัวที่ 1) และ `0x4B` เป็นเซนเซอร์ฝั่งขวา (เริ่มทำงานตัวที่ 2) อย่างแม่นยำ พร้อมรองรับกรณีแยกบัสสำรอง (`Wire` 21/22 และ `Wire1` 18/19)

## 🛠️ สรุปการแก้ไขเพิ่มเติมในโค้ดเวอร์ชันใหม่

### 1. แก้ไขฝั่ง Arduino (`esp32_c7_prototype.ino`)
- **สร้างคลาส `SafeBNO085` แทนที่ไลบรารี `SparkFun_BNO080` เดิม:**
  - แก้ปัญหา `Guru Meditation Error: StoreProhibited` (บั๊ก I2C ของ ESP32 Core 3.0.x เมื่อชิป NACK กลางคัน)
  - เช็ค `waitWriteAck()` (`beginTransmission` / `endTransmission`) ก่อนเรียก `requestFrom()` ทุกครั้ง
  - จำกัดขนาดการอ่าน SHTP ครั้งละไม่เกิน **32 ไบต์** (~2.9 ms ที่ 100 kHz) เพื่อไม่ให้เกินเพดาน Hardware Timeout 13.1 ms ของซิลิคอน ESP32
  - ยกเลิกการสั่ง `softReset()` แล้วรอเพียง 50 ms ที่ทำให้ชิปยังไม่พร้อมและเกิด NACK โดยเปลี่ยนเป็นอ่าน SHTP ทันที และหากจำเป็นต้องรีเซ็ตจะใช้ `safeSoftResetAndWait()` ที่รอชิปบูตครบ 450 ms พร้อมเช็ค ACK 5 ครั้งติดกัน
- **ระบบตรวจสอบสายไฟและสลับขาอัตโนมัติ (Electrical PinCheck & Auto-Swap):**
  - เช็คสถานะทางไฟฟ้าของขา `D21` และ `D22` ตอนบูต (`OK_PULLUP_3V3`, `FLOATING`, หรือ `LOW_STUCK`) พร้อมฟังก์ชัน `unstickI2CPins()` ส่งคล็อก 16 ลูกเพื่อปลดล็อกกรณีสาย SDA ค้าง
  - หากไม่พบอุปกรณ์บน `(SDA=21, SCL=22)` บอร์ดจะทดลองสลับเป็น `(SDA=22, SCL=21)` อัตโนมัติเผื่อเสียบสายสลับกัน
- **การคำนวณมุมศีรษะจากเซนเซอร์คู่ (Dual-Ear Circular Midpoint) และ Protocol v2:**
  - ตั้งศูนย์ (Zero Calibration) แยกอิสระรายตัว (`offsetPitchL/R`, `offsetRollL/R`, `offsetYawL/R`, `offsetC7`)
  - เมื่อทั้ง `0x4A` และ `0x4B` ทำงานพร้อมกัน จะคำนวณค่าเฉลี่ยเชิงมุม (`circularMidpointDeg`) ของหูซ้ายและหูขวาเพื่อให้ได้มุมกลางกะโหลกที่แม่นยำ และส่งออกเป็น JSON **Protocol v2** ความถี่ 5 Hz (ทุก 200 ms)
  - field หลัก: `protocol_version: 2`, `geometry_id`, `tilt_estimated`, `mpu_tilt` (มุม MPU ที่ C7 เทียบตอนตั้งศูนย์ ไม่ผสม pitch, `null` ถ้าไม่มี MPU), `mpu_tilt_raw`, `head_pitch`, `head_roll`, `head_yaw`, `cva_angle`
  - CVA ใช้แบบจำลอง 2 ท่อนในระนาบด้านข้าง (geometry 1) roll/yaw ไม่เข้าสูตร ดู [`docs/FORMULA.md`](docs/FORMULA.md)
  - มีระบบ Auto-Reconnect / Health Check ทุก 3 วินาที หากสายหลุดแล้วเสียบใหม่จะกลับมาอ่านค่าต่อได้เองโดยไม่ต้องรีบูตบอร์ด
